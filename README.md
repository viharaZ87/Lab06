___ HydrationReminder App ___

This project is built for the "Mobile Application Development (Lab 06)". It demonstrates how to implement local device notifications and multi-tab navigation using Expo Router in React Native.

Features Implemented:=
- Tab Navigation:- Multi-tab layout using Expo Router ('Reminder', 'Tips', and 'About' tabs).
- Local Notifications:- Scheduled repeating reminders using 'expo-notifications' with foreground handling.
- Customization:- Ability to input custom reminder messages and set interval times in minutes.
